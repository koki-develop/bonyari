# 開拓村 (settlement)

森の中の開けた土地に二家族が入植し、村になり、城壁に囲まれた中世ヨーロッパ風の町へ育っていくのを、斜め上から見下ろして眺める作品。魔物の襲撃がある。

## 仕様として決まっていること

- 見せ方は斜め上から見下ろす固定の平行投影。視点は拡大縮小と移動だけで、回転はしない（ユーザーが判断した）。
- 育ち方: 入植（テント）→ 丸太小屋の集落 → 礼拝堂と酒場のある村 → 柵（パリサード）で囲う → 石の城壁と門楼で囲った町、で頭打ちになる。町になってからは、建て替え（木造から石造り）と年ごとの出来事（市の日・収穫祭）、襲撃と再建で変化を続ける（ユーザーが判断した）。
- 育つ速さの目安（実時間。じっくり長く眺められるように、とユーザーが判断した）: 家 1 軒が着工から完成まで 45 分ほど、1 時間に 1〜3 軒。柵が一周するのが 6〜8 時間、石の城壁が一周するのが 10〜13 時間。いまの実測（シード 1〜4）は、家 1 軒が中央値 41〜44 分、柵が 6.0〜8.0 時間（36〜48 日目）、石の城壁が 11.2〜13.4 時間（67〜80 日目）。人口は 190〜200 人ほどで、家の数で頭打ちになる。
  - 速さを決めているのは、建物 1 棟が足場に囲まれている時間の長さ。村は家が足りなくなってから次の家を建て始め、移住者は空いた家があるときだけ来るので、1 棟にかかる時間がそのまま育つ速さになる。大工の手はふだん余っているので、建てる手間を増やしても人手が足りなくなるわけではない。
  - 調整するところ: 建てる手間の倍率（`sim/pace.ts` の `TOIL`。建てる・壊す・焼け跡の片付け・修理・舗装・柵）、城壁の同時に建てる区間の数（`sim/council.ts` の `RING_AT_ONCE`）、建てる順番と人数の条件（`plan` の `wishes`）、`sim/buildings.ts` の `KINDS` の資材と手間。木を切る・石を切り出すといった、見て分かる動作の長さには `TOIL` をかけない。大工は数回に分けて手を動かし、合間にひと息つく。
  - 町になってからは、町なかの木造の家の半分（見た目の番号で決まる）を石造りか町家に 2 棟ずつ建て替える（`RENEWING`）。住んでいる家族はそのあいだ近所に身を寄せる。
- 家族の家（`Household.home`）は、燃えても建て替えても同じ敷地の建物のまま変わらない。建っていないあいだは別の家に身を寄せ（`lodging`）、建ち直したら戻る。空き家の数には身を寄せている人も数えるので、そのあいだは移住者を入れない。
- 手の空いた大人は、昼のあいだ家のまわりの用事をする（畑の世話・薪割り・川での洗濯と釣り・井戸の水汲み・粉屋やパン屋への使い。`sim/jobs.ts` の `chore`）。家の中や同じ場所に固まって立ち尽くさない。
- 起きる時刻は人ごとに違い（パン屋は早く、子どもは遅い）、警報が解けたあとも少しずつ外へ出てくる。みんなが一斉に動かない。
- ページを閉じているあいだは世界を進めない。開き直したら保存から続ける（ユーザーが判断した）。
- 襲撃（`sim/raids.ts` の `RAIDS`、ユーザーが判断した）:
  - 間隔は日数で決める（1 日の長さを変えても日数のまま、とユーザーが判断した）。
  - 小（狼・盗賊。畑・家畜・柵を荒らす）: 2 日（20 分）ごと。
  - 中（ゴブリンの一団。1〜2 棟が燃える）: 3 日（30 分）ごと。家が 5 軒建ってから。
  - 大（竜。町になってから。大群と交互）: 12 日（2 時間）ごと。
  - 昼も夜も来る。中と大は、前の襲撃の焼け跡がすべて建て直されるまで来ない。焼け跡の片付け・修理・建て直しには、ふだんより多くの人が集まる（`sim/jobs.ts` の `MENDING_HANDS`）。これがないと建て直しが中の襲撃の間隔より長くなり、焼け跡の残る時間が長くなる。いまの実測では中の襲撃は 33〜37 分ごと。
  - 建物は燃えたり壊れたりするが、人の死は描かない。自警団から襲撃の大きさに見合う数人（最大 12 人。竜のときは衛兵と魔法使いだけ）が出て、町の端の襲撃者が来る側で待ち、森から出てきた襲撃者を槍で迎え撃つ。衛兵と魔法使いは動く相手の先を狙って射る（竜は `dragonAt` で先を読む）。残りは家に逃げ込む。襲撃者は 100 秒で諦めて森へ帰る。
  - 襲撃者は、槍を向けてきた相手とはその場でやり合い、狙いは変えない。松明は狙った家から 7 m 以内でしか投げない。仲間と重ならないように少しずつ間を空ける。
  - 人は倒されないが、襲撃者を怖がって見せる（ユーザーが判断した）。戦いに出ていない人は、襲撃者が 10 m 以内に来たらしていることをやめて走る。走る向きは、近くの襲撃者それぞれの進む先を読んで、いちばん離れていられる向き（川と家の中は除く）。そのあと襲撃者のいない側の建物へ逃げ込む（`sim/jobs.ts` の `flee`）。逃げ込む先は、襲撃者の近くの建物と、そこへの道が襲撃者の近くを通る建物を避けて選ぶ（`sim/council.ts` の `shelterNear`）。燃え出した建物・崩れた建物には誰も残らない。
  - 襲撃者が離れた火事は、警報が解ける前でも消しに行く（竜が 40 m 以内にいる火事は除く。1 つの火事に 8 人まで）。
  - 襲撃は見つけられることが大事（小さく目立たない襲撃は「敵がどこにいるか分からない」とユーザーが判断した）。襲撃者は人と同じくらいかそれより大きく描き、暗い縁取りと光る目で地面から浮かせる。数も多め（狼 5〜7 頭、盗賊 5〜7 匹、一団 10〜13 匹とオーガ、大群 18〜24 匹とオーガ 3 体）。狙う先は、いま眺めている場所（`World.attention`、画面の中心の地面）に近いものから選び、森の縁の 34〜55 m 先から出てくる。
- 夜は暗くしすぎない（ユーザーが判断した）。空の明るさに下限があり、家が 4 軒を超えたら踏み固められた通り・広場のまわり・門に松明が立つ（町になったら鉄の角灯）。暗くなって手ぶらで外にいる人は明かりを持つ。
- ステージの広さは `sim/terrain.ts` の `WORLD`（270 m × 320 m）。広げすぎると重くなる（ユーザーが判断した）。
- UI の文言は開始画面だけ。数字（人口・日付など）は画面に出さない。
- 1 日 = 実時間 10 分、1 年 = 12 日 = 2 時間（`sim/world.ts` の `TIMEKEEPING`。ユーザーが判断した）。天気は共有の天気の 8 割ほど降る（`WEATHER`）。空に飛行機は飛ばない（`SKY`）。
- 音は物の音と生き物の声だけで、人の話し声は入れない。打つ音・叩く音は共有の `resonate` で作る。発振器だけで作った打撃音は電子音に聞こえるので使わない。鋭いクリック音、突然大きな音は使わない。
- タブが隠れていても時間と音は止めない。10 秒ごとと、ページが隠れたとき・閉じるときに `localStorage` へ保存する（`platform/store.ts`）。URL パラメータで場面を指定したとき（`seed` と開発用のパラメータ）は、保存を読まず上書きもしない。

## アーキテクチャ

依存の向きは `sim/` ← `render/`、`sim/` ← `audio/` の一方通行。

- 座標は m。x が右、y が奥（画面の上）、z が上。平行投影で、画面の列は `x / S`、行は `-(y sinE + z cosE) / S`（`render/projection.ts`。`S` = 0.2 m、仰角 35°）。同じ画素なら高い面ほど手前にあるので、奥行きの比較は高さで行う。
- `sim/terrain.ts`: 地形。谷を流れる川、ゆるい起伏、奥の丘。どれもシードと位置だけで決まる関数。
- `sim/plan.ts`: 町の設計図。最初にシードからすべて決める: 広場、街道と通り、城壁の輪（川で切れる）と門と塔、区画（教会・酒場・製材所などの特別な区画と住宅の区画）、畑、牧草地、井戸、歩くための道のグラフ。建物は育つにつれてこの上に建つ。
- `sim/nav.ts`: 道の探し方。近くて間に何もなければまっすぐ、そうでなければ通りへ出て通りを行く。まっすぐ行けるかは、川と城壁の線で分けた区画と、建物の敷地の格子（町が変わるたびに `Town.version` を見て作り直す）で決める。通りへの出入りの区間が川の曲がりにかかるときは岸沿いに行く。立ち止まる場所は `standable` で川と家の中を避ける。
- `sim/forest.ts`: 森の木（オーク・シラカバ・トウヒ・マツ・ヤナギ）。入植者が見つける開けた土地と牧草地だけは最初から木がない。村は森を切り開いて広がる。
- `sim/council.ts`: 村の判断。次に何をどこに建てるか（`plan` の `wishes` の順）、仕事の割り振り、移住者の受け入れ、開く畑と通り、舗装、襲撃のあとの建て直し、牛車の数。
- `sim/jobs.ts`: 一人ずつの次の仕事の選び方と、仕事ごとの手順。仕事は `sim/tasks.ts` の手順（歩く・働く・運ぶ・待つ…）の平らな並びで、`runTask` が一歩ずつ進める。遠くにいる人は、帰り道のぶん早く寝床へ向かう。
- `sim/construction.ts`: 建てる・壊す・片付ける・舗装する・柵を張る、などの手間が世界を変えるところ。手間の量には `sim/pace.ts` の `TOIL` をかける。
- `sim/animals.ts`: 羊・牛・鶏・犬・カラス・カモ・牛車の牛。はぐれた家畜は道を通って自分の牧草地へ戻る。
- `sim/raids.ts`・`sim/fire.ts`: 襲撃と火事。
- `sim/market.ts`: 市の日の行商人。夜明けに牛車で来て広場の露店で一日過ごし、午後に帰る。住人ではないので `World.traders` に別に持ち、保存しない。
- `sim/festival.ts`: 年に一度の収穫祭（1 年の 9 日目）。昼に広場へ提灯を張り、夕方に焚き火を焚いて、輪になって踊る。
- `sim/fence.ts`: 牧草地の柵の形。門から一周する線で、張った長さのぶんだけ描く。
- `sim/world.ts`: 全体。長い経過は `MAX_STEP` 刻みで進める。`sim/record.ts`: 保存形式。仕事は保存せず、再開したら状態から選び直す。運んでいた物はその場に置く。
- `render/`: 地面・木・建物は 64×64 画素のタイルに G バッファ（素材・法線・高さ・持ち主）として描き、光が変わったら少しずつ塗り直す（`render/renderer.ts`）。毎フレーム重ねるのは、川の水面、動く明かり、人と動物と襲撃者、煙や火の粒、雨と雪。
  - 影は 0.5 m の格子の高さ図を太陽の向きに掃いて作る（`render/shadow.ts`）。落葉樹の影は葉の量に合わせて薄くなる。影の縁は格子の段が見えないようにディザでずらして引く。
  - 夜は空の明るさに下限（`render/shading.ts` の `NIGHT`）がある。目が暗さに慣れた明るさで、町が読めるようにする。曇りと雨の日は、雲に遮られた日の光の一部を空からの光として足す。
  - 画素は常に整数倍に拡大する。開いたときは CSS の 2 ピクセル（広い画面は 2.5）で 1 画素（`render/layout.ts`）。
  - タイルを描くのは重いので、1 フレームに使う時間に上限がある（`DRAW_BUDGET`）。まだ描いていないタイルが見えたら中心に近いものから描き、それまでは地面の無地の色を出す。古くなったタイルは描き直すまで前の絵を出す。手が空いたフレームでは視野の外 2 タイルまで先に描いておく。描いたタイルは捨てずに持つ。
  - 空と遠くの山は、視点が動かない間は 3 フレームに 1 回だけ描き、あいだは前の絵を写す。
  - 竜は `render/dragon.ts`。胴は背骨に沿って並べた円盤、脚は関節の鎖、翼は骨と膜の三角形で、その場で描く。部位（胴の輪切り・脚・翼・角・顎）はそれぞれ奥行きを持ち、奥から順に描く。胴を最後に描くと手前の翼が隠れる。影は太陽の向きに地面へ落とす。火の粒と明かりは口から出す。口の位置は `dragonBody` で胴の形と同じ計算から求め、`render/effects.ts` と共有する。
  - 通りの明かりは `render/streetlamps.ts`。置き場所は通り・家・時代が変わるたびに決め直し、明かりの色は窓明かりと同じ格子（`gatherLamps`）に足す。
- `audio/`: 単発音と祭りの曲は起動時に `OfflineAudioContext` で合成する（`bank.ts`・`tune.ts`）。音の出どころは世界の位置で、画面の中心の地面を耳にして、距離で大きさと左右を決める（`engine.ts`）。単発音の大きさは耳のすぐそばで鳴ったときの最大値（`PEAK`）で決める。遠くまで届くのは鐘・警鐘・竜の声。

## 守るべき不変条件

- 設計図と森はシードだけから作る。保存するのは建物・木の状態・人と家畜などで、設計図の作り方や森の作り方、保存する状態の形を変えたら `sim/record.ts` の `FORMAT` を上げる。
- 人は川に入らない（浅瀬を除く）。`sim/sim.test.ts` の「river」のテスト（4 シード、30 日）で確かめる。人は家の中を通り抜けず、家の敷地の中で立ち止まらない（井戸・石切り場・製材所・鍛冶屋の軒先・城壁の輪・橋は通れる）。
- 区画・畑・牧草地は重ならず、すべての区画と畑が谷の外へ出る道につながる。`sim/sim.test.ts` の「plan」のテストで確かめる。
- 襲撃は必ず終わる。襲撃者がどこにも行けなくても、`GIVE_UP` 秒で諦め、逃げ出して `FLEE_TIME` 秒で消える。
- 画素ごとのループの中ではメモリを確保しない。目安はデスクトップで、ふだん 1 フレーム 1 ms 以下、いちばん引いた視点で 3 ms 前後、タイルを描いている間も 20 ms を超えない。
- シミュレーションの 1 歩は人口 300 人でも 0.05 ms 前後。毎歩すべての人・動物について回る処理の中で、全員や全建物を探し直さない（ID と敷地は `World`・`Town` の索引で引く。地面の高さ・川・通り道の区分は前もって格子や表にしてある）。
- 町の中の仕事の集計（`Council.tally`）は仕事が始まるときと終わるときに増減させて保つ。住人の `p.task` を差し替えるのは `updatePeople` の中だけにする（行商人は集計に入らない）。

## 確認のしかた

開発サーバーでは URL パラメータで場面を指定できる: `seed`、`age`（その日数だけ村を生きさせてから見せる。見ているときより長い 0.5 秒刻みで進めるので、150 日でも 7 秒ほどで開く）、`day`（0〜11、その日まで進める）、`time`（`HH:MM`）、`weather`（`clear|cloudy|rain|storm|snow`）、`timescale`、`showcase=1`（すべての種類の建物を一度に建てる。建設中と焼け跡も混ぜる）、`raid=wolves|thieves|band|horde|dragon`（その襲撃をすぐ始める）。

- 例: 育ちかけの村は `?seed=1&age=15&time=10:00`、柵の村は `?seed=1&age=50&time=10:00`、城壁の町は `?seed=1&age=90&time=10:00`、収穫祭は `?seed=1&age=30&day=8&time=20:00`、市の日は `?seed=1&age=30&day=1&time=11:00`、竜は `?seed=1&age=90&raid=dragon`。
- `window.settlement` から `{ world, renderer, audio }` にアクセスできる。`renderer.viewport` の `setHome(列, 行)`・`home()`・`zoomTo(倍率, x, y)`（x, y は CSS ピクセル）で視点を動かせる。視点を動かすのはページが開いて最初の描画が済んだあとにする。
- 人は 8 画素ほどしかない。見た目の確認は `zoomTo` で拡大し、デバイスピクセル比 2 で小さく切り抜いて撮る。
- 育つ速さは `sim/world.ts` を Node で直接動かして測れる（1 日 = `update(1)` を `TIMEKEEPING.secondsPerDay` 回）。柵が閉じたかは `Council.walled(world, "palisade")` で見るが、閉じたのと同じ一歩のうちに石の城壁が始まって柵が壊され始めることがあるので、石の城壁の区間ができていることも閉じた印に数える。
- 音のバッファに NaN が混じると、マスターの後段が壊れてそれ以降すべて無音になる。音を作り直したら、全バッファの値が有限であることを確かめる。`#start` を押せば `AudioContext` が動き、`audio.master` に `ScriptProcessorNode` をつなげば音の大きさを測れる。
