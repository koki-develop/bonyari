# アリの巣 (ant-nest)

屋外の地面を縦に切った断面で、アリの巣が一匹の女王から育っていくのを眺める作品。

## 仕様として決まっていること

- 見せ方は屋外の地面の断面。上に空・遠景・芝、下に土の断面があり、巣は断面の中に掘られる。室内のアントファームにはしない（ユーザーが判断した）。
- 新しい巣は、羽のある女王が 5 月の午後に舞い降りるところから始まる。女王は羽を落とし、入口と最初の部屋を一匹で掘り、入口をふさいで最初の卵を産み、蓄えだけで最初の働きアリを育てる。育った巣から始める案は採らなかった（ユーザーが判断した）。
- 1 日 = 実時間 5 分、1 年 = 1 時間（`sim/world.ts` の `TIMEKEEPING`）。冬ごもりも含めて 1 年を回す（ユーザーが判断した）。冬は巣口をふさぎ、いちばん暖かい深い部屋に集まってほとんど動かない。ただし眠るのは真冬（12 月中旬〜2 月初め、実時間で 5〜6 分）だけで、その前後の寒い時期はアリがゆっくり動くだけにする。冬眠が長いと退屈だとユーザーが判断した（`sim/world.ts` の `WINTER_REST`）。
- 雨は共有の天気の 4 割ほどしか降らず、降っても早く上がる（`sim/world.ts` の `WEATHER`）。雨の間はアリが巣にこもって見どころがないので、ユーザーが減らすと判断した。巣口をふさぐのは強い雨のときだけで、雨が上がれば地面が乾ききる前に開ける。
- 土の中の明るさは時刻で変えない。夜になるのは空と地上だけ（ユーザーが判断した）。
- 触れる要素は、地上をタップするとパンくずが落ちることだけ。地面に落ちているパンくずは最大 10 個。画面が巣全体に足りないときだけ、ドラッグ・ホイール・上下キーで視点を上下に動かせる。
- 数字（匹数・日付・時刻など）は画面に出さない。アリの死は描かない。寿命を迎えた働きアリは、最後の採餌で断面の奥の草むらへ歩き去り、戻らない。これで巣は満員のまま止まらず、毎年新しいアリが育つ。
- 音は「土に耳を当てたような」音。アリの音（掘る・歩く・土を落とす）は近く、地上の音（風・雨・鳥や虫・雷）は土越しにこもらせる。粒がはじけるような鋭いクリック音は使わない。ピチャピチャ・クチャクチャと聞こえて不快だとユーザーが判断した。アリの足音は一匹ずつ鳴らさず、歩いているアリの数と近さで大きさが変わる、ひと続きの柔らかいサラサラにする。
- タブが隠れていても時間と音は止めない。10 秒ごとと、ページが隠れたときに `localStorage` へ保存する（`platform/store.ts`）。URL パラメータで場面を指定したとき（`seed` と開発用のパラメータ）は、保存を読まず上書きもしない。

## アーキテクチャ

依存の向きは `sim/` ← `render/`、`sim/` ← `audio/` の一方通行。

- 座標は mm。x が右、y が上（元の地表が 0）。断面は 1 mm 四方のセルの格子（`sim/geometry.ts`）で、描画も 1 画素 = 1 mm。
- `sim/soil.ts`: 手つかずの地面。地表の起伏、土の層（表土・ローム・粘土）、石。どれもシードと位置だけで決まる関数。
- `sim/plan.ts`: 巣の設計図。女王の入口と最初の部屋から、下へ延びる縦坑、その脇の部屋、二つ目の出入口、枝分かれした縦坑まで、コロニーが何年もかけて掘るすべてを石をよけて最初に作る。部屋も通路も中心線（`sim/line.ts`）を持ち、子は親の中心線の上から始まる。各セルには掘る順番と、中心線に沿った位置 `(s, u)` がある。
- `sim/nest.ts`: 掘られた巣の今の状態。どのセルが空いているか、各部分をどこまで歩けるか（`s` ごとの `u` の幅）、入口の栓の詰まり具合、そして中心線をつないだグラフ上の道順（`route`）。
- `sim/surface.ts`: 地上。運び出した土の山（入口のまわりはくぼみに保つ。雨でならされ、少しずつ崩れる）と、断面の縁に生える草（エノコログサ・ヒメジョオン・イネ科の草。アリが登る。一本にアブラムシがつく）。
- `sim/climate.ts`: 深さごとの地温と水分の 1 次元の柱。世界時間で熱と水を拡散させるので、1 日の暖かさは浅くしか届かず、季節の暖かさは深くまで遅れて届く。幼虫の育ち、アリの動きの速さ、冬ごもり、ぬかるみの見た目がここから決まる。
- `sim/colony.ts`: アリ・幼生・物（食べ物・まゆの殻・羽など）とコロニーの状態の型、生物としての定数。
- `sim/tasks.ts`: アリの行動。仕事は `step` を持つ平らなデータで、一歩ごとに歩くか立ち止まるかを決める。仕事の選び方は、年齢（若いアリは子守り）とコロニーの必要（巣の広さ、幼虫の空腹、見つかった餌、入口の開け閉め）で重みをつける。
- `sim/world.ts`: 全体。移動（中心線に沿って歩き、行きと帰りで左右に分かれてすれ違う）、コロニーの判断（部屋の選び方、冬ごもり、雨と冬の入口の封鎖、結婚飛行の日）、幼生の発育と産卵、落ちてくる虫。長い経過は `MAX_STEP` 刻みで進める。
- `sim/record.ts`: 保存形式。掘ったセルは連続区間の列にして保存する。仕事は保存せず、再開したら状態から選び直す。運んでいた物はその場に置く。
- `render/`: 1 フレームの流れは、空（共有）→ 遠くの山と木立 → 芝（数回/秒だけ描き直す層）→ 土の断面 → 積もった雪 → 巣の中の物・幼生・アリ → 草 → 地上の物とアリ → 雨・雪・ホタル → 土の粒。
  - 画素の大きさは CSS の 1.5〜2.5 ピクセルに収め、巣全体（`FRAME`）が入る整数倍を選ぶ（`render/layout.ts`）。入らない画面ではドラッグで上下に動かせる。
  - 地上はピンホールカメラで描く。断面は目から 0.25 m 先、目の高さは地表から 30 mm。視線は西北西で、夏の夕日が景色の中に沈む。
  - 土の断面は、セルごとの無照明の色を持っておき、掘られた所と土の山が変わった所だけ描き直す（`render/soil.ts`）。毎フレーム、光・濡れ・凍結を掛ける。地表より下は一定の光（`render/renderer.ts` の `UNDERGROUND`）、地表より上の土の山は時刻の光で照らす。巣の中の物・幼生・アリも一定の光で描く。掘った穴の奥の壁は、細かい土をまぶした明るい色にして上の縁の下に影を落とす。黒いアリが穴の中で見えるようにするため。
  - アリは小さなベクターの形を 4×4 のサブサンプルで描いたスプライトにして、大きさ・向き（32 方向）・脚の歩み・触角ごとにキャッシュする（`render/sprites.ts`）。巣の中は上から、地表では横から見た形。胴は輪郭をはっきり、脚と触角は細く半透明にする。
- `audio/`: 単発音は起動時に `OfflineAudioContext` で合成する（`bank.ts`）。かじる音・落とす音・固める音は、なめらかな立ち上がりと減衰をつけた、帯域の広いフィルター付き雑音で作る。共鳴や発振器の音は使わない。音の出どころは断面上の位置で、耳の位置（巣の上のほう）からの距離で大きさと左右を決める（`engine.ts`）。

## 守るべき不変条件

- 巣の設計図はシードだけから作る。保存するのは掘ったセルそのものなので、設計図の作り方が変わってもセルは失われないが、並べ直した巣はつじつまが合わなくなる。設計図の作り方や保存する状態の形を変えたら、`sim/record.ts` の `FORMAT` を上げる。
- アリも幼生も、空いたセルの上にしかいない。部屋や通路の中の立ち位置は `Nest` の幅で決め、掘っている途中の面の手前に留める。`sim/sim.test.ts` の「open ground」のテストで確かめる。
- 入口の栓は壁ぎわから詰め、真ん中の穴を最後にふさぐ。穴がふさがるのは全員が中に戻り、栓の中に誰も立っていないときだけ。見張りは栓の内側で待つ。アリが締め出されたり閉じ込められたりしないようにするため。
- 保存するときは、運ばれている幼生や物も運んでいるアリの居場所に記録し、再開したらそこに置く。
- 画素ごとのループの中ではメモリを確保しない。目安の負荷はデスクトップで、スマホの画面（195×422 画素）なら 1 フレーム 4〜5 ms、PC の画面（720×450 画素ほど）で 8 ms 前後。
- 保存されたコロニーは、途中で保存しなかった場合と同じには進まない（仕事を保存しないため）。巣・幼生・物・アリの居場所は保たれる。
- 落ちてくる物の跳ね返りは、1 刻みより短い跳ねなら止まる。隠れたタブの長い刻みでも、落ちた物がいつまでも跳ね続けないようにするため。

## 確認のしかた

開発サーバーでは URL パラメータで場面を指定できる: `seed`、`age`（その日数だけコロニーを生きさせてから見せる。30 で約 2 年半）、`day`（0〜11、その日まで進める）、`time`（`HH:MM`）、`weather`（`clear|cloudy|rain|storm|snow`、時計を進めずに落ち着かせる）、`timescale`。

- 例: 育った巣の夏の午後は `?seed=12345&age=36&day=4&time=15:00`、冬ごもりは `?seed=12345&age=20&day=10&time=11:00`、女王の到着は `?seed=7&age=0.02`。
- `timescale=0.0001` で世界がほぼ止まるので、細部を撮るのに使える。
- `window.antNest` から `{ world, renderer, audio }` にアクセスできる。`renderer.panBy(行数)` で視点を動かせる。
- アリは 1 画素 = 1 mm で 7〜12 画素しかない。見た目の確認は、デバイスピクセル比のまま小さく切り抜いて行う。
- 音のバッファに NaN が混じると、マスターの後段が壊れてそれ以降すべて無音になる。音を作り直したら、全バッファの値が有限であることを確かめる。`#start` を押せば `AudioContext` が動き、`audio.master` に `ScriptProcessorNode` をつなげば音の大きさを測れる。
